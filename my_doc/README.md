## 当前共识

1. 新建独立的山东麻将项目，逐步形成自己的产品和代码结构。
2. 面向 Windows、Android、iOS、macOS，尽量共用一套游戏代码。
3. 采用 Godot 路线；当前实现为 Godot 4.5.1 + GDScript。
4. 先把单机 AI、画面和山东规则做好，同时预留联网所需的接口。
5. 第二阶段做同一 Wi-Fi／手机热点下的局域网建房，公网连接最后考虑。
6. 山东玩法和建房约定先以原项目的山东实现为迁移基准。
7. 用户提供需求引导，不承担编码工作；开发、验证、打包与提交由助手推进。
8. 项目根目录保留两个双击入口：`启动游戏.bat`、`打包游戏.bat`。

- **已落地的实现选择**：为满足目标而采用的具体方案，不代表用户已逐项确认其最终样式或所有细节。
