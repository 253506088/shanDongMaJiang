## 网页怎么用

1. 模型选 **Speech-2.8 HD**；它支持在同一段文本内切换情绪。
2. 复制 [00-整批文稿.txt](00-整批文稿.txt) 全文到朗读文本框。
3. 按下表选中对应台词，在网页应用情绪。表中的“中性／生动／开心”等是网页选项，**不要把表格或情绪名称粘进正文**。
4. 先用女声 `Chinese_worker_female` 生成、下载；保留文本及情绪设置，再换男声 `Chinese_gravelly_storyteller_nv1` 生成、下载。语速先用正常的 `1.0`。

可以先把全文设成“生动”，再按下表调整过牌和真假结果；开牌、续轮维持“生动”。无需为不同情绪拆成五次生成。男声应短促、果断，保留音色质感但不要拖成说书；女声自然爽利。标点和少量语气词已写进稿子，逐句情绪仍需要在网页里设置。

## 稿子里的特殊标记

- **`<#3#>`：静音3秒。** 15句之间共14处，方便后续裁剪。空行只方便阅读，不代替静音标记。
- **`(sighs)`：叹气。** 放在“行吧”之前，表达认栽。
- **`(chuckle)`：轻笑。** 放在“逮到你了”之前，表达得意。“哈哈假牌”本身已有笑意，不再叠加长笑。

用户给的网页指南明确说明：选定文本段落即可应用情绪；支持笑声、轻笑、叹气等语气词；停顿可以点击 `<#>` 或手动输入。`(sighs)`／`(chuckle)` 的准确文本拼写由 [MiniMax 语音合成文档](https://platform.minimaxi.com/docs/api-reference/speech-t2a-http) 补充，当前文档说明这些语气标签用于 Speech-2.8。

**情绪与语气词是两种控制。** 本稿没有把 `(happy)` 或 `[难过]` 当作情绪指令：这份网页指南给出的操作是选中文本、应用情绪。纯文本文件无法保存网页里的逐句情绪选择；粘贴后仍需完成上表设置。若网页把叹气／轻笑标签显示为普通朗读文字，删掉这两个标签，分别用网页的“语气词 → 叹气／轻笑”插入同一位置。

## 下载后交回

两条建议命名为 `bluff-female-all.wav`、`bluff-male-all.wav`。网页能下载WAV就优先WAV；只有MP3也可以，保留原文件，不用自己转格式或裁剪。男女两条保持相同台词顺序，保留句间静音，我收到后再裁成各15段、整理响度并接入随机播报。合成后也保留实际模型和设置，方便重做不满意的句子。

[clips.json](clips.json) 是后续裁剪的顺序与命名清单。过牌用过牌者的角色性别；开牌及真假结果都用掀牌者的角色性别；无人跟、无人开时，计划沿用最后出牌者播续轮。角色性别与开局选人功能已经存在，继续默认望舒。
