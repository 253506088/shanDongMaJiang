# 唬牌机器人如何决定开牌和出牌（0.8.2）

机器人采用有记忆的规则策略和随机选择，没有使用大模型，也不会查看其他人的暗手。入口是 `scripts/bluff/core/ai.gd`，按席记忆在 `knowledge.gd`，动作节奏在 `session.gd`。

## 旧版的问题

旧版优先找匹配点数的牌，包含王；手牌排序把王放在前面，所以很容易先选王，再随机塞一张假牌。跟牌时仅有22%的机会追加牌，追加的还可能是真牌，实际诈唬率偏低。领出时通常选择最大的真牌组。开牌主要按固定概率、公开累计张数和是否最后一手判断，没有使用历次翻牌的去向或自己的已清记录。

0.8.2 保留原先尚未提交的无限领出修复，并重做策略、记忆与多行手牌；不沿用上述旧行为。

## 机器人究竟记住什么

每位机器人只有自己的独立视角：自己的手牌、各家剩余张数、公开的宣言和开牌结果，以及自己曾亲手扣下的牌。

- **公开转手**：你质疑上家的1张K，翻开是真K，你收走牌堆。此时每个人都知道你手里至少有1张K。你未再扣牌时，这条事实一直保留；别人的行动不会抹掉它。
- **扣牌后减弱**：你随后扣下一张，哪怕宣称的是3，也可能把K当假牌打出。机器人不能继续断言你一定握着K；确定下限减少，并保留衰减的可能性线索。宣称K或使用王的可能性会使对应线索衰减更快，但宣言本身不当作事实。
- **再次翻开后修正**：如果刚才那张翻开是3，原本那张K就仍在你手里；若翻开的是K，则跟随整堆转移到本次收牌人。大小王分别追踪，同点数多张和双副牌按数量累计。
- **自己的旧扣牌**：机器人知道自己曾经扣下的真实牌，若整堆后来被别人收走，它能记住这些牌也到了那个人手里。其他机器人只能知道各自有权知道的部分，收牌者可以看见自己收到的全手牌。
- **已清的牌**：自己打成死牌的真实牌，以及能从既有确定信息推导出的死牌，会从可用牌数中扣除。未翻开的他人牌面不会自动变成已知。
- **行为经历**：累计每位玩家被翻开的次数、其中说假的次数，以及实际质疑／跟牌／过牌的行为。开出的样本有选择偏差，因此只有限度地调整策略，不把几次真牌当作永远可信。

记忆独立于界面最多80条的日志，不会因换轮或日志截断消失；新的一局全部清零。真人左下的「本家已清」仍保持用户指定的含义，仅统计本人实际打出并出清的牌，不混入其他玩家记忆或推测。

## 先判断要不要开

1. **检查能否证明**：一副牌某点数连同两张王最多6张，两副最多12张。扣除自己握着的匹配牌、确定已清的匹配牌、确定在其他人手里的匹配牌、前面扣牌中自己确知的匹配牌；再结合出牌者原手牌张数和已知非匹配牌，计算这手最多可能有几张真牌。超过就开。若记忆足以证明这手全真，就不开。
2. **评估未确定的情况**：基础怀疑值38%，再参考对方既往翻牌真假、这次张数相对可能持牌量、此前收走的已知K／王、已减弱的持牌线索、本轮累计扣牌量。已知对方有K，会使1张K更可信，却不能证明这次扣下的就是K。
3. **衡量后果**：对方出完最后一手，提高开牌意愿；中央牌堆较大、开错代价高，降低冒险程度。最后用随机数作选择，避免每次同样的牌面都固定处理。

这里的“怀疑值”是行为策略参数，不是经过校准的数学真伪概率。只有标记为确定的情况才按证明处理；未知情况保留猜错、被骗和冒险的空间。

## 报牌者的许可判断（0.8.3）

若下家剩1–3张，机器人要开自己的上家时先申请，不直接翻牌。被保护的机器人只读取本席手牌和公开记忆来答复：怀疑值达到0.60才允许；本席可以全真跟完时，提高到0.85以保留跟牌机会。明确证明真／假仍取0／1。这些阈值是实现选择，不是用户已确认的最优策略。

拒绝后正常跟牌或过牌，同一宣言不重复申请；自由抢开其他机器人仍各评估一次，许可等待不会重掷已评估者的随机判断。

## 不开时，如何决定真假和出哪些牌

- 正常以约44%为有意诈唬的起点，根据各家实际开牌频率、自己有没有当前点数、收回大堆的风险作调整。不是每局固定掺几次假牌，也不承诺整体假牌率恰好44%。
- 假牌组确保至少有一张不符合宣称；优先甩较零散的普通牌，**不把王夹进假牌组**。可能是全假，也可能混合普通真牌与假牌。
- 真牌先用对应点数的普通牌，王留作以后补真牌；少量随机补王或单出王时，整组仍为真。若整手都能按当前点数作真牌出完，就直接出完。
- 自己领出时通常利用较大的普通牌组选择点数，同样大小的组随机取舍，也会改报别的点数来唬。跟牌沿用本轮点数；手中缺牌时可以诈唬、用王或过牌。
- 机器人倾向于较小、尚有可信度的假牌组，手多时可出到5张；这是策略选择，不是规则上限。真牌组和可直接获胜的整手不受这个数量约束。

固定手牌、各600次独立种子的专项测试中，领出实际假牌比例47%，跟牌48.33%；所有假牌均不含王。这只描述该测试样本，不代表每局、每种手牌都有同一比例，也不把自测写成用户已认可难度或乐趣。

## 真人出牌限制和展示

领出、跟牌均可选任意非空的一组手牌，**没有A、没有王，也可以整手10张宣称为A**。能否成真只在别人开牌时结算；单副牌10张A虽然一定为假，仍须先允许出牌，再由玩家质疑。

手牌不分页。普通手牌保持原布局；超过30张时自动分为2–4行，108张也全部展示并能跨行选择，行间保留角标和花色可见。可另点「放大查看手牌」逐张检查。选牌仍须按扣牌按钮确认。

## 顺位、自由抢开和节奏

顺位模式轮到自己才判断是否质疑。自由抢开模式，各机器人对同一手宣言只评估一次；别人的过牌不会给它重新抽一次随机机会，当前行动者也不会额外评估第二次。新宣言重新评估。多个机器人都想开时仍按席位遍历先受理一位，不模拟真人抢按速度。

标准／舒缓至少停顿2／2.8秒，机器人正常动作另加0–0.8秒波动，并等待语音展示；真人没有行动倒计时。开牌约4秒自动续轮，查看详情或暂停时冻结。尚未加入跨局学习、长期玩家性格模型或多步搜索；当前记忆只存在于本局进程内。
