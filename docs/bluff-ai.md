# 唬牌机器人的记忆与候选出牌评估（0.10.1）

机器人只读取本席裁剪视图，不查看其他玩家暗手。ai.gd负责质疑与许可，strategy.gd枚举、评价出牌，knowledge.gd记录本局信息，session.gd控制节奏。没有接入大模型，也没有跨局学习。

## 为什么改

用户指出“我手里有3张K，人机还敢出5张K”。三人一副牌时，K与两张王共6张；握着3张K的人可以直接证明5张K为假。旧版虽在**质疑**时检查牌数，**自己出牌**却先按约44%的起始概率决定诈唬，再随机挑1–5张，没有比较宣称的可识破程度及收堆后果。

已检查当前MahjongAI.rank()和前身工程src/game/variants/shandong/shandongAi.ts的rankDiscardOptions()。麻将牌效策略先枚举候选，比较出完后的向听、有效进张、公开余张和牌形。本次借用其“候选→后续局面→评分→选择”方式，评价指标改为唬牌自身的收益与风险，没有把麻将顺子、向听或规则搬进扑克牌。

## 候选如何生成和比较

领出比较13个可声明点数，跟牌只比较本轮点数。真牌候选覆盖不同张数的对应普通牌及王；假牌候选包含甩零散牌、普通真牌夹假牌两类，每类至少有一张不符声明的牌，仍不夹王。同点数的花色在规则与记忆中等价，不穷举每一种花色排列。

| 依据 | 行为 |
| --- | --- |
| 出完后的手牌 | 奖励甩牌数量及减少剩余点数组，关注能否留下下一次领出的全真收尾 |
| 王的后续价值 | 普通组够用时倾向留王补以后缺的点数；能全真出完时直接用完 |
| 可以证明的破绽 | 某家已知持牌或该家自己先前扣下的已知牌，足以否定声明时，排除假牌候选 |
| 未知持牌的分布 | 根据剩余牌池估计对手仅凭自身牌就能识破的风险，避免从1–5张中盲抽 |
| 开牌习惯 | 使用本局实际质疑频率和本席被翻出的真假经历，有限度调整风险 |
| 收回整堆 | 被抓时刚打出的牌回手，还要收旧中央牌堆并失去先手；空堆也有丢节奏的成本 |
| 开牌方式 | 自由抢开计入全部对手；顺位模式考虑前一家跟牌覆盖旧宣言，过牌才传递后续质疑机会 |
| 过牌 | 跟牌时将过牌一同评分；大堆上没有值得出的牌时可以等下一轮 |

粗略评分为：成功概率×（甩牌张数＋牌形改善－王的保留价值）－被开概率×（旧中央堆张数＋丢先手成本），另给全真收尾最高优先级。只在分数相近的候选间变化，不再人为维持固定诈唬比例。清掉孤张、保留整组及王是启发式权重，尚不是经过真人对局校准的最优参数。

这是一层出牌及出完后牌形评估，没有多步搜索或整场博弈求解。对手将怎样跟牌、是否放行质疑仍有不确定性。

## 怎样估计“别人能数出来”

一副牌每个声明点数最多6张匹配牌，两副12张，含大小王。如果宣称n张，任何对手只要能确认其中至少“总量－n＋1”张在声明之外，就足以证明为假。

从总牌池排除本席手牌、确定的死牌、确定的旧扣牌和各家已知持牌下限；剩下的未知牌按有限牌池分布计算各家可能持有的匹配张数。单家边缘分布用超几何分布，不读取实际发牌。未知死牌和未知中央牌也保留在未知池中，不能凭宣称当作已知牌扣掉。

已知某家握着3张K时，五K的破绽是确定事实；不知道K在哪家时，只是估计各家握有足够反证的可能性。在未知牌等可能分布的假设下，单家边缘分布按组合数计算；合并多家质疑、顺位覆盖和行为频率的模型是近似启发式，**不是校准后的实战概率**。

出牌者只把对手确实有权知道的信息用于确定反证：该对手自己的持牌，以及该对手亲自扣下、出牌者也能确定的牌。不会把本席私有的已清记录假定为全桌公共知识，也不假定低手牌玩家一定拒绝许可来为明显假牌找借口。

两副牌时5张K可能完全为真，不能硬编码禁出5张。真人领出和跟牌仍可任意非空选牌，包含无A无王时整手宣称10张A；机器人的候选筛选不是规则限制。

## 机器人记住什么

每位机器人独立保存自己的手牌、各家张数、公开宣言与翻牌，以及自己亲手扣下的牌。

- 公开K被收走后跟踪新持有人；旁人的行动不抹掉它。
- 持有人未知扣牌后降低确定下限，保留衰减线索。声明K不是出过K的证据，隐藏出牌也可能把K作为假牌打出。
- 再次翻牌能修正该次扣牌的不确定性，随后随收堆转移。普通同点数、双副牌、两种王分别计数。
- 本席旧扣牌转手时，仅本席能追踪这部分私有信息；其他席不能自动看见。收牌者可查看收到的完整手牌。
- 确定出清的匹配牌不再可用，未知死牌仍未知。真人“本家已清”继续只统计本人实际打出并出清的牌。
- 翻牌真假及质疑、跟牌、过牌经历存在选择偏差，只有限度影响策略。

记忆不依赖界面最多80条的日志；换轮保留，新局归零，不保存到磁盘。

## 质疑、最后一手与报牌许可

质疑仍先扣除自己持有、确定出清、其他人已知持有及旧扣牌的匹配牌，结合声明者原手牌量和已知非匹配牌判断。可证明为假就质疑，可证明全真就接受；其余参考记忆、软线索、对方被翻牌经历及收错大堆的代价，保留不确定选择。

本席正常跟牌时可以全真出完，优先完成收尾，不为猜开上一手放弃这条路径。若上一家已经出完，跟牌即认输，尚不能证明为真的最后一手会争取质疑机会；确认为真仍接受。许可与拒绝后的合法动作由原规则层校验，不绕过保护。

C→B→A中，A报牌后B开C仍需A许可。机器人A用自己的证据判断，能全真跟完时更倾向保留跟牌机会；明确反证仍支持放行。真人答复无倒计时，同一宣言拒绝后不重复申请。顺位模式轮到自己才开；自由抢开各机器人对同一宣言只评估一次。

标准／舒缓至少停顿2／2.8秒，动作另加0–0.8秒波动并等待语音；开牌约4秒后续轮，暂停或看详情冻结。此次没有缩短节奏。
