# 第一阶段验收记录

日期：2026-11-02。环境：Windows、Godot 4.5.1 标准版／Mono 版、Intel Arc；Android 11 / API 30 模拟器使用宿主 GPU 与 OpenGL ES 3。

## 规则与存档

`tools/test.ps1`：**36,482 项断言，0 失败**。

- 1,140 组原项目生成的胡牌／计分参考牌例。
- 64 组经典／牌效 AI 选择与报听状态参考。
- 12 局确定性模拟，组合覆盖二五八将／乱将、吃牌开关与 AI 模式。
- 每步核对 144 张实体牌及每种张数，结算积分总和不变。
- 验证报听锁手、未报听不能普通自摸、实际弃牌才可声明、补花保留杠头、开杠换杠头、仅剩杠头流局、明搂付款倍数、点炮／自摸／抢杠／地胡支付方式。
- 拒绝错误座位、过期版本、伪造动作；座位视图不含其他未亮手玩家的手牌或牌墙顺序。对手暗杠只显示张数，自己的暗杠可见，视图裁剪不修改权威状态。
- 验证中途／结算后的日志重放；结算不会重复扣分；损坏主存档可恢复上一手备份，续玩收回本家 AI 托管。

已生成签名调试 APK（包名 `com.qingyutai.shandongmahjong.debug`），安装到本次启动的只读测试模拟器。关闭 Wi-Fi 和移动数据后验证：

## 苹果平台与发布边界

macOS 通用未签名 ZIP 已导出；没有在 Mac 上运行，未做签名／公证。iOS 仅提供导出预设与同一套 GDScript 源码，没有在本 Windows 环境生成可安装 IPA，也没有 iOS 实机验收；需 Mac、Xcode、导出模板与 Apple 签名身份。

本次产物是第一阶段单机游戏。局域网建房、公网连接、应用商店发布均未包含在“通过”范围内。

## 素材与构建

运行不依赖 Node、Python、外部 API 或网络。Node 仅用于从旧项目生成参考数据；Python 仅用于重建美术／字体和获取官方构建工具。美术、音效、字体及上游规则的许可随源码和程序内“开源许可”入口提供。

缓存、下载、安装包与截图均被 `.gitignore` 排除。核心运行源码、资源、导出配置、参考牌例和可重复执行的工具提交到仓库。具体迁移细节见 `rule-baseline.md`。
