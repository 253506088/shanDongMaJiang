# 牌桌视觉重做 · 2026-11-03

对应用户对原生山东麻将与本地 H5 项目的画面对比。参考工程为 `D:/code/my/2/开源麻将/lianhuaguangdongmahjong`，本轮仅修改山东麻将仓库。

## 视觉

- 浅雾白界面、深石板色文字、海青强调色与少量珊瑚色。大厅、设置、应牌、查牌和结算使用同一套无衬线排版和面板样式。
- 桌框采用浅色陶瓷外沿、银色细缝、青色内边和低饱和布面。原创细缝线与海岸曲线只放在外围，牌河区域保留空间。
- 长焦透视相机约 67° 俯角，36° 视场角。三家未公开手牌绕短边立起；明搂和局末公开手牌平放，暗牌始终没有真实牌面材质。
- 圆角麻将采用暖白树脂面、青蓝背壳与独立底面纹样，解析曲面法线表现倒角。牌背图案按实际小尺寸检查，自己的手牌也带同色底沿。
- 中央计数器与当前决策方向灯保持清晰；当前座位同步显示边框和圆点。珊瑚色仅标记杠头等重点。

## 牌山和交互

`wall_slots` 与私有牌墙并行保存物理位置。正常摸牌移除头部，补花取杠头前一张，开杠取真实墙尾；剩余上层牌失去支撑时落到桌面，杠头不被上层遮挡。HUD 的杠头与牌山中的牌相同，点击实体牌可以查牌。

牌位与几何单独放在 `table_layout.gd` 和 `tile_geometry.gd`。近侧花牌采用两排排布，八张花牌也不进入屏幕手牌区域。副露包含吃碰来源方向和补杠叠牌。

原项目的牌面、逐牌语音、应牌展示、出牌节奏、查牌和声明后的合法杠牌改动一并完成交付。桌面仍为悬停查牌、单击出牌；触屏交互保留已有约定。
