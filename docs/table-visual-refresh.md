## 交付美术的接入

庭院主选 01 使用原生 1376×768 图片，不使用交付中的 2560×1440 插值版。背景铺在实时 3D 牌桌后方，并以低对比遮罩适配大厅及牌桌的信息区域；桌子、牌山、牌河与手牌保持独立渲染。四位头像统一裁切、缩小并使用圆形透明边缘，配细金圆框；昵称、积分和庄家／听牌状态留在独立文字区。

交付织物原图含 8px 横纵周期，透视缩小后容易形成网格。`tools/prepare_delivered_art.py` 抑制横纵周期分量，以周期边界的低通过滤和细节降对比保留细织物质感，再生成柔和明暗、细滚边与圆角透明度；当前完整桌面贴图为 `assets/textures/felt_delivered.png`。暖木边沿、阴影与开源牌面继续由既有材质和模型承接。

原始导出、命名交付图、运行图之间的来源对应和 SHA-256 记录在 `assets/art_manifest.json`。候选 02、放大图与原始交付归档留在本地，不进入运行资源。整理过程与备份边界见 [素材说明](asset-guide.md)。

## 牌山和交互

`wall_slots` 与私有牌墙并行保存物理位置。正常摸牌移除头部，补花取杠头前一张，开杠取真实墙尾；剩余上层牌失去支撑时落到桌面，杠头不被上层遮挡。HUD 仅保留对应牌图与牌名，删除“杠头”“开杠即摸”等重复标签，具体含义通过悬停解释；牌图与牌山中的牌相同，点击实体牌可以查牌。

牌位与几何单独放在 `table_layout.gd` 和 `tile_geometry.gd`。近侧花牌采用两排排布，八张花牌也不进入屏幕手牌区域。副露包含吃碰来源方向和补杠叠牌。

原项目的牌面、逐牌语音、应牌展示、出牌节奏、查牌和声明后的合法杠牌属于既有体验基线。桌面仍为悬停查牌、单击出牌；触屏交互保留已有约定。美术调整不改变规则和存档格式。

手牌悬停上抬 12px、触屏选中上抬 14px；悬停仅移动牌面与底壳，保持点击区域不动，避免鼠标停在下缘时反复进入／退出。新摸牌继续保留间隔与短标识。辅助按钮保留文字并配统一线形图标，各状态使用同一内边距，悬停不改变宽度。

桌面查牌框和短提示统一为深绿半透明底，普通文字用暖白、当前牌和听口用浅金。去掉手牌上与查牌框重复的系统牌名 tooltip。轮到本家应牌时，左栏目标牌框亮起金边，目标牌图、牌名和来源玩家共同提示当前决策。

触屏点击操作按钮保留当前选牌及报听模式，避免按下时重建按钮导致释放失效。只有点到桌面空白才取消选择，并同时清空上次双击记录；对应莲花麻将 `clearMobileSelection` 对操作行的排除逻辑。
