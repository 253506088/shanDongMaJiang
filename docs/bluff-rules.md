# 唬牌：独立单机玩法（0.8.2）

大厅点「唬牌」，选择 3–6 人，默认为你和两名机器人。3 人使用一副 54 张扑克牌，4–6 人使用两副 108 张牌，均含大小王。均匀发完；五人局有三家 22 张、两家 21 张，多一张的位置随机轮转。

## 本桌规则

1. **猜拳定先手**：你选择石头、剪刀或布，所有参与者同时出拳。全相同或三种齐全为平局；出现两种时，获胜手势的玩家继续决胜，直到只剩一名胜者。已被淘汰时可点「观看下一轮猜拳」。每局都重新猜拳。
2. **领出**：从手中选任意非空的一组牌（可整手），指定 A、2–10、J、Q、K 任一点数，背面扣下。宣称点数与实际手牌独立，可以全部为真、部分为假或全部为假。
3. **跟牌不限张数**：用户 2026-11-06 明确选择“不限张数”；每次可扣下任意非空的一组手牌，仍宣称本轮点数，不受上一手张数限制。也可选择过牌或质疑。
4. **顺时针表态**：屏幕上从本人下方出发，依次经过左侧、上方、右侧玩家。新出牌会重置本轮过牌计数。单次过牌不退出本局，也不退出后续轮次。
5. **质疑窗口**：默认仅当前轮到的人可开最近一手；有人过牌后，下家仍可开该手。开局也可选「任何人可抢开」，包含非当前行动的真人与机器人。出牌者不能质疑自己；后续出牌覆盖质疑目标，首次受理的有效质疑结束当前堆牌。
6. **只翻最后一手**：任何一张既不等于宣称点数、也不是大小王，即抓包成功，出牌者收回中央整堆，由质疑者领出。全部符合（大小王可替任意点数），则质疑者全收，由刚才出牌者领出。历史扣牌不因收牌而公开；收牌者自己的新手牌正常可见。
7. **死牌**：出牌后，其余所有玩家都依次过牌且无人质疑，整堆背面移出本局，最后出牌者重新领出任意点数。死牌只显示张数，牌面不公开。
8. **最后一手**：出空手牌先显示「待确认」，仍允许质疑。其他人全过、有人合法跟牌表示接受，或质疑证明为真后，率先出完者获胜。若被抓包则收回整堆继续打。跟牌接受前一家的最后一手时，新选择的手牌不会扣除。

质疑权限的两种约定来自用户提供的规则。最后一手的确认与单局胜者制，是补足未指定细节的本版实现选择；跟牌不限张数是用户明确回复；2026-11-06后续进一步明确领出也不限张数，没有A或王仍可整手宣称10张A。没有回合外积分、固定局数或联网功能；结束后可继续同配置，也可重新入座选择人数。

## 操作与节奏

- 点选或按住鼠标划选，随后按「扣下 X 张 Y」确认；同一次划动每张只切换一次。触摸及其配对鼠标事件去重。点桌面空白或「清空选择」取消选择。
- 手牌不分页；超过30张时自动排成2–4行，最多108张同时显示，角标与花色保持可见。支持跨行选牌，「放大查看手牌」可逐张检查，两副牌的相同牌面仍是两张独立牌。
- 领出时明确选择宣称点数；跟牌锁定点数，允许假牌。界面不会用“合法牌型”阻止唬牌。
- 开牌逐张标注「真／假／万能」，停留约 4 秒后自动进入下一轮，不再要求点确认；大组开牌可展开查看全部，查看详情或暂停时冻结倒计时。猜拳胜者展示约 1.8 秒后自动开始；整局已结束时保留胜负画面，不自动重开。
- 其余玩家全过后，当次动作就清理死牌并开始新一轮，直接显示新的领出操作，没有中间停留画面。下一位机器人保留正常思考与报牌节奏。
- 左下「记牌 · 本家已清」只记你自己实际打出、并随死牌移出的牌。例如你打出的 1 张 4 已清，就记「4 已清 1 张」。不统计其他人的盖牌，不按宣称点数猜测，不把质疑后收回手里的牌算成出清；自己的假牌按真实点数记，大小王单独记。新一局清零。
- 本轮右侧常驻显示所有人的每手张数，例如「听松 1＋3＋2 张」，包括自己；可滚动查看长记录，点详情按出牌先后查看整轮。新一轮自动清空本轮列表，已清牌记忆继续保留。
- 标准节奏至少 2 秒，舒缓至少 2.8 秒，并等宣言语音结束后再留出停顿。真人无行动倒计时；自由抢开时，其他玩家仍可按约定质疑最近一手。
- 男／女声、静音、传统／国风牌面、人数与质疑约定独立保存。规则、牌局记录及完整手牌窗口暂停机器人；后台暂停不会反复切换成继续。
- 退出即结束当前唬牌局，下次重新发牌，不读写麻将或斗地主牌局。

## 架构与信息边界

`scripts/bluff/core/` 仅处理实体牌、规则状态和机器人策略；`session.gd` 管理节奏与轮次，`ui/table.gd` 只接受按席裁剪视图，`voice.gd` 只朗读公开宣言。唯一应用桥接为 `mode.gd`。

机器人拿不到其他人的手牌、中央堆牌身份或其他人打成死牌的身份。它根据自己的牌、已清牌、公开收牌去向、扣牌后减弱的持牌线索、历次翻牌真假与当前风险判断质疑；真假出牌混合，假牌不夹王，使用独立随机源。具体策略和信息边界见 [机器人决策说明](bluff-ai.md)。记牌器独立维护每席亲自打成死牌的真实计数，只在该席视图中发送自己的计数；不向真人展示其他角色的记忆。累计记牌不依赖会截断的整局日志。规则核心用独立种子控制洗牌、发牌与猜拳，可确定性复现。

跨玩法只复用 `scripts/poker/ui/` 的牌面绘制与主题目录，以及字体、庭院、织物等基础素材。斗地主原路径保留薄兼容入口；唬牌运行代码没有导入斗地主引擎、会话、AI 或语音。牌图仍保存在既有素材目录，避免重复复制同一素材。

本版不改麻将正常 v1／场地 v2／v3 存档、重放动作含义或 LAN 协议 3。动作携带 `round_id` 与 `revision`，拒绝旧局回调、过期动作和重复操作。

## 语音与素材

牌面来源和许可沿用 [牌面说明](doudizhu-card-art.md)。唬牌新增男女各 127 段（1–108 张数量、13 种点数、6 种事件），只打包离线 WAV。每次宣言顺序播放数量和点数；不朗读扣牌真实牌面。

生成工具为 `tools/generate_bluff_audio.py`，使用现有固定版本的 Kokoro / sherpa-onnx 缓存，不新增模型下载；模型与运行时遵循 Apache-2.0。完整来源、模型哈希、逐文件 SHA-256、台词与长度在 `assets/licenses/bluff-voice-manifest.json`。生成语音不等同于真人录音，其自然度与真实手机手感尚需用户确认。

验收命令：`tools/test.ps1`、`tools/test_ui.ps1 -Suites bluff_ui_test`。构建后另用 `tests/bluff_package_test.gd` 指向 Windows EXE 的内置资源做发布包检查。具体结果见 [验收记录](verification.md)。
