# 附近同桌（0.4.0）

## 怎样一起玩

1. 所有人安装同一版本，连接同一个 Wi-Fi，或者由一位玩家开启手机热点，其他设备连接该热点。
2. 在大厅点击「附近同桌」。一位玩家填写昵称，选择二五八将／乱将、允许／不允许吃牌、经典／牌效 AI，然后「创建房间」。Windows 和安卓均可担任房主。
3. 其他玩家从自动刷新的房间列表点击「加入」。列表暂时没有发现时，可输入房主界面显示的 IPv4 地址；默认端口无需填写。
4. 客人核对规则后点击「我准备好了」，房主点击「开始对局」。支持 1–4 位真人，空位自动使用普通机器人；房主一个人也可以先开桌。
5. 每局结束由房主开始下一局，每局轮庄、累计积分、无限续局。房间设置开局后固定；开局前修改设置会取消客人的准备状态，需重新确认。

牌桌沿用现有鼠标／触屏操作，每个人的手牌都在屏幕下方；中央风位保持实际座位身份。真人没有出牌倒计时。报听／明搂后非胡的新摸牌自动打出，胡牌和合法杠牌保留选择。

「房间」菜单可以查看成员和离线状态；菜单和设置不会暂停整桌。空位机器人一直参与对局；真人掉线默认保留座位，轮到该玩家时等待本人。房主可以开启「掉线托管」，回归玩家重新连接后收回控制权。主动离开会释放座位并由电脑补位；已开局房间不接受新的玩家，断线者可凭本进程保存的凭据回原座位。房主离开会解散整桌。

## 网络和平台

- 不需要账号、公网服务器或互联网。对局使用 ENet 可靠 UDP（默认 `32141`），房间发现使用 UDP 查询与单播回复（`32142`）；发现数据只含房间摘要。
- Android 导出开启 `INTERNET`、`ACCESS_NETWORK_STATE`、`ACCESS_WIFI_STATE`。房主应保持游戏在前台，避免后台休眠中断服务。
- Windows 防火墙应允许游戏在当前可信局域网中通信。本工程不会自动修改防火墙。
- 同一个 Wi-Fi 名称不保证设备可以互相通信：访客网络、AP／客户端隔离、VPN 或热点实现可能阻断广播或直连。广播受限时可输入地址；直连也被阻断时需要调整网络或更换热点。
- 当前实现为 IPv4 局域网，不支持公网房间码、NAT 穿透、房主迁移或 IPv6 专用网络。macOS／iOS 未进行本轮平台接入验收。

## 数据边界

房主运行唯一的 `GameEngine`，客人只能提交本席的局号、版本号和合法动作 ID。房主重新检查座位身份、当前决策、版本和动作。客户端不能指定手牌、积分、牌墙或胡牌结果。

每个客户端只收到 `GameEngine.view(seat)` 的私有视图。不会发送完整快照、牌墙顺序、动作日志、其他玩家的暗手或暗杠牌面；暗杠事件也单独遮蔽。`SeatView` 只转换显示位置，不参与判定。房主设备是可信的权威端；此版局域网传输没有 TLS／二维码指纹认证。

正常模式继续兼容既有存档与重放。局域网不会覆盖 `current_match.json`；完整牌谱只允许房主在结算后导出。**本版房间只在运行中的进程内保存**：支持进程存活时重新连接，尚不支持关闭应用后的房间恢复、房主日志恢复或扫码邀请。此前文档中的这些迁移目标仍属后续范围。

0.3.0 增加独立场地开关，默认关闭；房主配置、客人核对，开局后每局统一随机抽取一项。网络和发现协议升级为 2，拒绝旧协议混玩。占星目标与结果、三选一候选、换牌选择不发给他人；瓦西子只分享实体透明手牌，并隐藏牌山与杠头。正常单机存档继续 v1，场地单机存档使用 v2；联网房间仍不覆盖单机文件。详见 [场地规则](field-rules.md)。

0.4.0 允许房主在开局前选择关闭、每局随机或指定某项场地，房间与发现列表显示具体选择；修改后客人需重新准备。指定场地在续局时保留。天使先正常摸牌，有需要才由使用者主动追加两张；候选和完整手牌只向本席提供。当前网络／发现协议为3，不能与0.3.0客户端混玩。新场地单机存档为v3，并继续兼容v1／v2旧日志。

## 验证

`tools/test.ps1` 包含局域网发现、真实 ENet 回环多席会话、界面状态的无界面检查，且继续运行既有规则、AI、重放和 UI 逻辑回归。回环使用实际 socket，不代替 Windows／安卓设备间的 Wi-Fi、热点、后台与防火墙验证。

`tools/test_lan_process.ps1` 在重建 Windows 包后使用四个独立发布程序进程无界面联机，完成一局并进入第二局，核对四个座位及累计积分。测试文件本身不进入安装包。

该轮没有进行真实渲染截图或跨设备实机验收；交付包与测试结果见 [验收记录](verification.md)。2026-11-05 用户澄清，允许启动游戏和可见测试窗口，禁止的是接管电脑操作；历史未测项目仍需实际验证，不能因授权澄清而记为通过。
