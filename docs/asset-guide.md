# 素材说明

第一版无需用户补图即可完整运行。

- 43 张牌面（含牌背）：`tools/make_assets.py` 用原创几何纹样、点筒、竹节、一索鸟与字体生成，256×368 PNG。
- 桌布：固定随机种子的织物噪声、原创山形等高线和圆形刻度，1536×1536 PNG。
- 大厅：原创分层山形背景，1600×900 PNG。
- 音效：由正弦波、谐波与短噪声合成的点击、牌声、提示和胡牌音，不使用不明来源录音。
- 字体：Google Fonts 的 Noto Sans SC 与 Noto Serif SC，SIL OFL 1.1。字体做静态字重和常用中文字集裁剪，许可文件一同保留。生成流程见 `tools/prepare_fonts.py`。

这些图片是可复现的项目原生美术资源；没有从原项目拷贝人物、桌布或声音。需要更强的个人风格时，可在后续替换桌布与大厅插画，不影响规则核心。

可选后续文生图方向（当前版本不依赖这些图片）：

> 横版 16:9 东方书房静物插画，夜晚温润的青玉色与深松绿色，象牙白麻将牌和少量哑光黄铜细节，柔和侧光，安静克制的桌游氛围；右侧为具有手绘质感的器物与远山，左侧留出干净大面积深色空间供标题和按钮，清晰前中后景，细腻纸张肌理，不要文字、数字、Logo、水印、角色和大面积高光，避免写实赌场与霓虹灯。

生成图片应只用作装饰底图，不把按钮和牌面文字烘焙进图片。
