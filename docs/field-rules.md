# 场地规则

2026-11-05 新增的可选对局增强。场地规则与山东、四川、福建等地方玩法是两个维度；本版仍以山东麻将为基础玩法。关闭场地规则即为正常模式，不会因为选用不同地方玩法而变为特殊模式。

开局设置中单独选择“场地规则”。默认关闭；开启后每一局独立、等概率抽取一项，全桌共用，下一局重新抽取。同一项可能连续出现。基础将牌、允许吃牌等开关继续生效：能组成特殊顺子不等于绕过“不允许吃牌”。

## 玩家通用说明

- **每人每局一次**：一位玩家用过，不消耗其他玩家的机会。次数在下一局重置。
- **额外一番**：在本局基础胡牌分上乘二，结算单独列出来源；同一奖励不会因为命中多张而重复计算。
- **私下查看**：只有使用者能看到；房主权威状态、其他客人的座位视图和机器人的可见信息分别处理。
- **仍须合法听牌和胡牌**：报听、明搂后的锁手规则继续执行；允许杠牌的场地也必须保持听口，除“新生”明确撤销报听的阶段。
- 本文中的“字牌”为东、南、西、北、红中、发财、白板；“数牌”为万、筒、条。“听一种牌”按牌面种类计算，不按未见张数计算。

## 十六项规则

| 场地 | 给玩家的说明 |
| --- | --- |
| **衔尾蛇** | 万、筒、条各自首尾循环，**八九一、九一二**也算顺子，可用于吃牌和胡牌。不同花色不能混搭。用户确认原“九二三”为笔误，不将其增加为顺子。 |
| **大力金刚指** | 每人每局一次，在自己的出牌回合将一张手牌变成白板，其他人看不到原牌。报听、明搂后不能使用。白板超过四张时，可向已有白板杠续添一张，再取一次杠头补牌。 |
| **东南西北中** | 东、南、西、北、红中中，**任意三种不同牌**可组成顺子，例如东南西、东中西、北中南、南西北。发财、白板不参与。 |
| **新生** | 每人每局可撤销一次报听。撤销后持续亮出手牌，允许重新整理牌型；再次听牌只能明搂，只能自摸，胡牌按明搂计分。 |
| **瓦西子麻将** | 每种普通牌的四张实体牌中，随机一张为暗牌、三张为明牌；只有进入玩家手牌后的明牌公开，牌山始终不可见。暗明属性跟随实体牌，不随同种牌的数量改变。花牌照常公开补花。 |
| **宽容** | 已碰出的一组牌，可以接任何其他玩家打出的同种牌补成明杠，再取杠头。胡牌响应仍优先；已听时不能改变原听口。 |
| **上架** | 每人每局一次，在自己的出牌回合将**一组吃牌或碰牌**完整收回手牌，重新组牌。杠牌、花牌不撤回；报听、明搂后不能使用。曾经公开的牌不会因此变成“无人知道”。 |
| **癞子** | 红中在听牌和胡牌组合中可代替任意普通牌，也可当红中本身；二五八将按替代后的牌型判断。吃、碰、杠仍使用实体牌，不能用红中冒充别的牌来副露。 |
| **占星Ⅰ** | 每人每局一次，在自己的出牌回合私下查看牌山前端接下来的四张牌。数量不足时只显示实际可查看的牌；这是查询当时的顺序，之后的摸牌、补花及能力可能改变结果。 |
| **占星Ⅱ** | 每人每局一次，选择一位已经听牌的对手，私下查看当时的全部听口。若使用者随后向该目标点炮，目标该次胡牌额外加一番；其他人点炮不触发。 |
| **天使的施舍** | 每人每局一次，在普通摸牌时私下三选一，其余两张回到牌山。已经报听或明搂时不能使用，补花和杠后补牌也不使用。候选、选择结果不向其他玩家公开。 |
| **无字天书** | 去掉全部二十八张字牌，补入二十八张随机数牌，花色、数字各自随机且允许重复。花牌保留，总数仍为一百四十四张。同种牌超过四张时可续杠，每添一张再取一次杠头。 |
| **听单张** | 只能在听口恰好为**一种牌面**时报听或明搂；两种及以上听口不能声明。本局合规胡牌额外加一番。不限于单钓将，一边听等只要牌面唯一也符合。 |
| **换牌** | 开局补花后、首次出牌前，每人选三张给下家，同时收取上家的三张。必须先选数牌；数牌不足三张才可用字牌补足。四人选择完成后统一交换。 |
| **天选** | 开局公开三种随机且互不相同的数牌。最后一张胡牌牌面命中其中任意一种，额外加一番；只加一次。天胡只要起手胡牌中含任意天选牌即可。 |
| **天选Ⅱ** | 最后一张胡牌牌面等于胡牌前公开杠头，额外加一番，普通自摸和点炮也适用。杠后自摸使用本次取出前的杠头；天胡只须起手胡牌中包含开局杠头。 |

## 牌型与计分细节

特殊顺子同时参与吃牌、胡牌、听口和预估番数计算。东南西北中的全字牌组合仍可构成风一色，不要求字牌顺子有固定摆放顺序。衔尾蛇只改变数牌顺子，九二三没有连续关系。

癞子通过自然牌计数与剩余红中数量进行记忆搜索，不读取其他人的暗牌。七对、十三幺、十三不靠、碰碰胡、将一色、风一色及单一花色均提供替代后的有效牌型用于计分。结算保留实际胡牌手牌，可额外记录计分采用的红中替代组合，避免把不同替代方案中互不相容的番型相加。

红中替代用于组成牌型；“字暗刻”花分仍按实际手牌计算。两张红中代一张白板拼成白板刻子，不会凭空多送字暗刻花；实际持有三张红中的字暗刻花仍保留。计分比较各有效替代方案，采用得分最高的一项。

无字天书与大力金刚指允许同种牌超过四张。已有四张的杠每续添一张，仍只占一组面子，但再次补牌，并再计一次对应杠花分；五张白板明杠计两次字明杠花，六张计三次。六张相同牌可用于三对，七对的豪华数按每四张计一次，不把六张当作两组豪华。

无字天书的听口不会列出本局不存在的字牌；剩余张数使用本局牌种总量。大力金刚指只公开白板总量增加，不公开哪个牌种减少，以免泄露被替换的暗牌。

瓦西子场地按“牌山不可见”处理，连同平时公开的杠头也盖住，仍从原位置补牌。其他玩家的明牌与暗槽分别排布，避免利用暗牌在排序中的位置反推牌面。新生也可撤销明搂，撤销后明牌状态和明搂计分继续保留，需重新声明才能胡牌。天使的施舍只在普通摸牌前且牌山至少有三张非保留候选时可用；未选中的两张保持原顺序放回前端，选到花牌时照常补花。

## 架构与验证

玩家文案唯一目录为 `scripts/core/field_rules.gd`；`FieldRules.IDS` 列出稳定规则 ID，`info()` 提供名称、短说明和完整说明。`Rules.winning / waits / chi` 增加可选 `field_id`，不传参继续走原有正常规则；计分通过 `flags.field_id` 和 `flags.field_bonus` 扩展。

专项规则检查：`tests/field_rules_test.gd`，全程无界面，覆盖循环和字牌示例、唯一听口、无字听口、重复杠花、天胡加番、红中穷举替换对照及评分有效性。引擎、联网隐私、存档重放和界面验证由相应场地专项补充，真实手机手感与可见渲染验收需另行记录，不由这些纯规则测试代替。

### 设计解释

用户已确认“东南西北中”采用任意三种不同牌，保留全部例子；“上架”采用撤回一组吃或碰，杠牌与花牌不撤回，以保持补牌和手牌张数规则清晰。衔尾蛇的九二三也已确认为笔误，按八九一、九一二实现。
